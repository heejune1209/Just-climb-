
1) 상점에서 아이템 구매 흐름
- Player → UI_Shop → ItemManager → CurrencyManager → DataManager → UI 갱신까지의 흐름
```mermaid
sequenceDiagram
    participant Player
    participant ShopUI as UI_Shop
    participant ItemM as ItemManager
    participant CurrM as CurrencyManager
    participant DataM as DataManager
    participant InvUI as UI_Inventory

    Player->>ShopUI: 버튼 클릭 → BuyItem(Feather)
    activate ShopUI

    ShopUI->>ItemM: TryBuy(ItemType.Feather)
    activate ItemM

    Note over ItemM: 가격만큼 골드 차감 시도
    ItemM->>CurrM: SpendGold(price)
    activate CurrM

    CurrM->>DataM: AddGold(-price)
    activate DataM
    DataM->>DataM: Save() (→ JSON 파일 덮어쓰기)
    DataM-->>CurrM: OnSaved(Current)
    deactivate DataM

    CurrM-->>ItemM: OnGoldChanged(newGold)
    deactivate CurrM

    ItemM->>DataM: AddItem(Feather,1)
    activate DataM
    DataM->>DataM: Save()
    DataM-->>ItemM: OnSaved(Current)
    deactivate DataM

    ItemM-->>InvUI: OnItemCountChanged(Feather,newCount)
    deactivate ItemM

    activate InvUI
    InvUI-->>InvUI: 화면 갱신
    deactivate InvUI

    deactivate ShopUI

```

2) 인게임에서 아이템 사용 흐름
- 키 입력 → 사용 가능 체크 → 효과(FeatherUse) 적용 → JSON 저장 → UI 갱신
```mermaid
sequenceDiagram
    participant Player
    participant Input as ItemInput
    participant ItemM as ItemManager
    participant Effect as FeatherUse
    participant DataM as DataManager
    participant InvUI as UI_Inventory

    Player->>Input: 키 '1' 누름
    activate Input

    Input->>ItemM: UseItem(Feather, Player)
    activate ItemM

    Note over ItemM: 쿨다운 & 보유 개수 체크
    ItemM->>ItemM: CheckCooldown()
    ItemM->>ItemM: HasItem()?

    Note over ItemM: 사용 로직 실행
    ItemM->>Effect: Use(Player)
    deactivate ItemM

    activate Effect
    Effect-->>Player: Apply buff (GameManager)
    deactivate Effect

    activate ItemM
    Note over ItemM: 사용 후 개수 차감
    ItemM->>DataM: RemoveItem(Feather,1)
    activate DataM
    DataM->>DataM: Save()
    DataM-->>ItemM: OnSaved(Current)
    deactivate DataM

    ItemM-->>InvUI: OnItemCountChanged(Feather,newCount)
    deactivate ItemM

    activate InvUI
    InvUI-->>InvUI: 화면 갱신
    deactivate InvUI

    deactivate Input

```
