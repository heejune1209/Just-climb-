# 스팀 자동배포 워크플로우 가이드 (2024)

## 개요
이 가이드는 GitHub에 코드를 푸시하면 자동으로 Unity 게임을 빌드하고 스팀에 업로드하는 CI/CD 워크플로우를 구성하는 방법을 설명합니다.

## 사전 준비사항
- GitHub 계정 및 리포지토리
- Unity 라이센스 (Pro 또는 Plus)
- Steamworks 계정 및 App ID
- Steam SDK 다운로드

## 1. 스팀 설정

### 1.1 Steamworks 파트너 사이트 설정
1. https://partner.steamgames.com/ 로그인
2. App & Packages > [Your App] > SteamPipe 탭 이동
3. Depots 설정:
   - Depot 1: Windows 빌드용
   - Depot 2: macOS 빌드용 (선택사항)
   - Depot 3: Linux 빌드용 (선택사항)

### 1.2 Steam Build 설정 파일 준비
프로젝트 루트에 `steam/` 폴더 생성:

```
steam/
├── app_build.vdf
├── depot_build_windows.vdf
├── depot_build_macos.vdf (선택사항)
└── depot_build_linux.vdf (선택사항)
```

### 1.3 app_build.vdf 파일 생성
```vdf
"appbuild"
{
    "appid" "YOUR_APP_ID"
    "desc" "Just Climb Auto Build"
    "buildoutput" "../build_output"
    "contentroot" "../builds"
    "setlive" "default"
    "preview" "0"
    "local" ""
    
    "depots"
    {
        "DEPOT_ID_WINDOWS" "depot_build_windows.vdf"
        "DEPOT_ID_MACOS" "depot_build_macos.vdf"
        "DEPOT_ID_LINUX" "depot_build_linux.vdf"
    }
}
```

### 1.4 depot_build_windows.vdf 파일 생성
```vdf
"DepotBuildConfig"
{
    "DepotID" "DEPOT_ID_WINDOWS"
    "contentroot" "windows/"
    "FileMapping"
    {
        "LocalPath" "*"
        "DepotPath" "."
        "recursive" "1"
    }
    "FileExclusion" "*.pdb"
}
```

## 2. GitHub Actions 워크플로우 설정

### 2.1 GitHub Secrets 설정
Repository Settings > Secrets and variables > Actions에서 다음 추가:

- `UNITY_LICENSE`: Unity 라이센스 내용
- `UNITY_EMAIL`: Unity 계정 이메일
- `UNITY_PASSWORD`: Unity 계정 비밀번호
- `STEAM_USERNAME`: Steam 계정 사용자명
- `STEAM_PASSWORD`: Steam 계정 비밀번호
- `STEAM_SHARED_FILE_SECRET`: Steam Guard 공유 파일 시크릿

### 2.2 워크플로우 파일 생성
`.github/workflows/steam-deploy.yml` 파일 생성:

```yaml
name: Steam Auto Deploy

on:
  push:
    branches: [ main ]
    paths-ignore:
      - '**.md'
      - 'Documentation/**'
  pull_request:
    branches: [ main ]
    paths-ignore:
      - '**.md'
      - 'Documentation/**'

env:
  UNITY_LICENSE: ${{ secrets.UNITY_LICENSE }}
  UNITY_EMAIL: ${{ secrets.UNITY_EMAIL }}
  UNITY_PASSWORD: ${{ secrets.UNITY_PASSWORD }}

jobs:
  build:
    name: Build and Deploy
    runs-on: ubuntu-latest
    
    steps:
    # 1. 체크아웃
    - name: Checkout repository
      uses: actions/checkout@v4
      with:
        fetch-depth: 0
        lfs: true
    
    # 2. Git LFS 파일 체크아웃
    - name: Git LFS checkout
      run: git lfs checkout
    
    # 3. 캐시 설정
    - name: Cache Unity Library
      uses: actions/cache@v4
      with:
        path: Library
        key: Library-${{ matrix.targetPlatform }}-${{ hashFiles('Assets/**', 'Packages/**', 'ProjectSettings/**') }}
        restore-keys: |
          Library-${{ matrix.targetPlatform }}-
          Library-
    
    # 4. Unity 라이센스 활성화
    - name: Request Unity License
      uses: game-ci/unity-request-activation-file@v2
      id: activation
    
    - name: Activate Unity License
      uses: game-ci/unity-activate@v2
      with:
        license: ${{ secrets.UNITY_LICENSE }}
    
    # 5. Unity 빌드 (Windows)
    - name: Build Windows
      uses: game-ci/unity-builder@v4
      with:
        targetPlatform: StandaloneWindows64
        buildName: JustClimb
        buildPath: builds/windows
        buildMethod: BuildScript.BuildWindows
    
    # 6. Unity 빌드 (macOS) - 선택사항
    - name: Build macOS
      if: false  # 필요시 true로 변경
      uses: game-ci/unity-builder@v4
      with:
        targetPlatform: StandaloneOSX
        buildName: JustClimb
        buildPath: builds/macos
        buildMethod: BuildScript.BuildMacOS
    
    # 7. Unity 빌드 (Linux) - 선택사항
    - name: Build Linux
      if: false  # 필요시 true로 변경
      uses: game-ci/unity-builder@v4
      with:
        targetPlatform: StandaloneLinux64
        buildName: JustClimb
        buildPath: builds/linux
        buildMethod: BuildScript.BuildLinux
    
    # 8. 빌드 파일 압축
    - name: Archive builds
      run: |
        mkdir -p artifacts
        if [ -d "builds/windows" ]; then
          cd builds/windows && zip -r ../../artifacts/windows-build.zip . && cd ../..
        fi
        if [ -d "builds/macos" ]; then
          cd builds/macos && zip -r ../../artifacts/macos-build.zip . && cd ../..
        fi
        if [ -d "builds/linux" ]; then
          cd builds/linux && zip -r ../../artifacts/linux-build.zip . && cd ../..
        fi
    
    # 9. SteamCMD 설치
    - name: Install SteamCMD
      run: |
        sudo apt-get update
        sudo apt-get install -y lib32gcc-s1
        mkdir -p steamcmd
        cd steamcmd
        wget https://steamcdn-a.akamaihd.net/client/installer/steamcmd_linux.tar.gz
        tar -xvzf steamcmd_linux.tar.gz
        cd ..
    
    # 10. Steam 로그인 및 업로드
    - name: Upload to Steam
      env:
        STEAM_USERNAME: ${{ secrets.STEAM_USERNAME }}
        STEAM_PASSWORD: ${{ secrets.STEAM_PASSWORD }}
      run: |
        # Steam 로그인
        ./steamcmd/steamcmd.sh +login $STEAM_USERNAME $STEAM_PASSWORD +quit
        
        # 빌드 업로드
        ./steamcmd/steamcmd.sh +login $STEAM_USERNAME $STEAM_PASSWORD +run_app_build steam/app_build.vdf +quit
    
    # 11. 빌드 아티팩트 업로드
    - name: Upload build artifacts
      uses: actions/upload-artifact@v4
      with:
        name: game-builds
        path: artifacts/
    
    # 12. Unity 라이센스 반납
    - name: Return Unity License
      uses: game-ci/unity-return-license@v2
      if: always()

  notification:
    name: Discord Notification
    needs: build
    runs-on: ubuntu-latest
    if: always()
    
    steps:
    - name: Send Discord notification
      if: env.DISCORD_WEBHOOK_URL != ''
      env:
        DISCORD_WEBHOOK_URL: ${{ secrets.DISCORD_WEBHOOK_URL }}
      run: |
        if [ "${{ needs.build.result }}" == "success" ]; then
          curl -H "Content-Type: application/json" \
               -X POST \
               -d '{"content":"🎉 Just Climb 빌드가 성공적으로 Steam에 업로드되었습니다!"}' \
               $DISCORD_WEBHOOK_URL
        else
          curl -H "Content-Type: application/json" \
               -X POST \
               -d '{"content":"❌ Just Climb 빌드가 실패했습니다. GitHub Actions를 확인해주세요."}' \
               $DISCORD_WEBHOOK_URL
        fi
```

## 3. Unity 빌드 스크립트 생성

### 3.1 Editor 폴더에 BuildScript.cs 생성
`Assets/Editor/BuildScript.cs` 파일 생성:

```csharp
using UnityEditor;
using UnityEngine;
using System.IO;

public class BuildScript
{
    [MenuItem("Build/Build Windows")]
    public static void BuildWindows()
    {
        BuildGame(BuildTarget.StandaloneWindows64, "windows");
    }

    [MenuItem("Build/Build macOS")]
    public static void BuildMacOS()
    {
        BuildGame(BuildTarget.StandaloneOSX, "macos");
    }

    [MenuItem("Build/Build Linux")]
    public static void BuildLinux()
    {
        BuildGame(BuildTarget.StandaloneLinux64, "linux");
    }

    public static void BuildGame(BuildTarget target, string platform)
    {
        // 빌드 설정
        string[] scenes = GetScenePaths();
        string buildPath = Path.Combine("builds", platform);
        
        // 빌드 옵션 설정
        BuildPlayerOptions buildOptions = new BuildPlayerOptions
        {
            scenes = scenes,
            locationPathName = Path.Combine(buildPath, GetExecutableName(target)),
            target = target,
            options = BuildOptions.None
        };

        // 빌드 실행
        var report = BuildPipeline.BuildPlayer(buildOptions);
        
        if (report.summary.result == UnityEditor.Build.Reporting.BuildResult.Succeeded)
        {
            Debug.Log($"빌드 성공: {buildPath}");
        }
        else
        {
            Debug.LogError($"빌드 실패: {report.summary.result}");
            EditorApplication.Exit(1);
        }
    }

    private static string[] GetScenePaths()
    {
        EditorBuildSettingsScene[] scenes = EditorBuildSettings.scenes;
        string[] scenePaths = new string[scenes.Length];
        
        for (int i = 0; i < scenes.Length; i++)
        {
            scenePaths[i] = scenes[i].path;
        }
        
        return scenePaths;
    }

    private static string GetExecutableName(BuildTarget target)
    {
        switch (target)
        {
            case BuildTarget.StandaloneWindows64:
                return "JustClimb.exe";
            case BuildTarget.StandaloneOSX:
                return "JustClimb.app";
            case BuildTarget.StandaloneLinux64:
                return "JustClimb";
            default:
                return "JustClimb";
        }
    }
}
```

## 4. 테스트 방법

### 4.1 로컬 빌드 테스트
```bash
# Unity 프로젝트 폴더에서
# Windows 빌드 테스트
Unity -batchmode -quit -projectPath . -executeMethod BuildScript.BuildWindows

# macOS 빌드 테스트
Unity -batchmode -quit -projectPath . -executeMethod BuildScript.BuildMacOS

# Linux 빌드 테스트
Unity -batchmode -quit -projectPath . -executeMethod BuildScript.BuildLinux
```

### 4.2 GitHub Actions 테스트
1. 테스트 브랜치 생성:
```bash
git checkout -b test-steam-deploy
```

2. 더미 파일 생성하여 커밋:
```bash
echo "# Test commit" > test_deploy.md
git add test_deploy.md
git commit -m "Test: Steam deploy workflow"
git push origin test-steam-deploy
```

3. Pull Request 생성하여 워크플로우 테스트
4. 성공 후 main 브랜치로 머지

### 4.3 Steam 업로드 테스트
1. Steamworks 파트너 사이트에서 빌드 확인
2. Steam 클라이언트에서 베타 브랜치 테스트
3. 게임 실행 및 기능 테스트

### 4.4 자동화 테스트 시나리오
```bash
# 1. 코드 변경 후 푸시
git add .
git commit -m "feat: 새로운 기능 추가"
git push origin main

# 2. GitHub Actions 로그 확인
# https://github.com/[USERNAME]/Just_Climb/actions

# 3. Steam 빌드 확인
# https://partner.steamgames.com/apps/builds/[APP_ID]

# 4. 게임 클라이언트에서 업데이트 확인
```
